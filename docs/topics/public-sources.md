# BeerDirect 公开信息源清单（第一版）

## 说明

这份文档用于整理 BeerDirect 第一阶段值得研究和优先接入的公开信息源。

目标不是一次列全所有来源，而是建立一批：

- 长期稳定更新
- 对啤酒行业有真实价值
- 适合归档、检索和专题研究
- 尽量便于自动采集

本文按以下方式组织：

- 来源类别
- 来源名称
- 主要价值
- 适合追踪的内容
- 接入建议（RSS / 网页抓取 / 人工整理）
- 初步优先级（P1 / P2 / P3）

---

## 一、官方组织与标准类

这类来源适合做 BeerDirect 的“基础事实层”。

## 1. Brewers Association
- 类别：协会 / 行业组织
- 价值：美国精酿行业最重要的官方来源之一
- 适合内容：行业新闻、统计、活动、风格与行业趋势参考
- 接入建议：官网栏目抓取 + 人工精选
- 优先级：P1

## 2. BJCP
- 类别：风格标准 / 评审体系
- 价值：风格研究基础来源
- 适合内容：风格定义、风格差异、风格历史脉络
- 接入建议：静态文档归档 + 主题映射
- 优先级：P1

## 3. World Beer Cup / Great American Beer Festival 官方页面
- 类别：比赛 / 官方活动
- 价值：适合建立比赛、风格与酒厂成绩档案
- 适合内容：获奖结果、比赛分类、评审动态
- 接入建议：结果页面抓取 + 年度归档
- 优先级：P1

## 4. 各国啤酒协会 / 官方展会网站
- 类别：行业组织 / 展会
- 价值：有助于补足区域市场信息
- 适合内容：本地行业动态、活动、政策变化
- 接入建议：人工精选为主
- 优先级：P2

---

## 二、行业新闻与媒体类

这类来源主要服务于“行业周报”和“品牌/市场时间线”。

## 5. Brewbound
- 类别：行业新闻媒体
- 价值：品牌、资本、渠道、市场动作非常重要
- 适合内容：融资、并购、扩张、渠道、品牌发布
- 接入建议：RSS / 网页栏目抓取
- 优先级：P1

## 6. Good Beer Hunting
- 类别：行业媒体 / 深度报道
- 价值：适合做品牌文化、行业趋势与深度观察
- 适合内容：长文、趋势、人物与酒厂故事
- 接入建议：人工精选 + 长文摘要
- 优先级：P1

## 7. The Full Pint
- 类别：啤酒新闻媒体
- 价值：适合产品发布、酒厂动态和美国精酿市场跟踪
- 适合内容：新品、联名、活动、酒厂新闻
- 接入建议：RSS / 网页抓取
- 优先级：P2

## 8. BeerAdvocate News / Features
- 类别：媒体 / 社区型内容
- 价值：品牌、风格与消费者感知补充层
- 适合内容：专题、榜单、趋势、品牌关注度
- 接入建议：人工精选
- 优先级：P2

## 9. VinePair（Beer 相关栏目）
- 类别：饮料媒体
- 价值：有助于观察更广义酒饮趋势中的啤酒位置
- 适合内容：趋势、消费变化、跨品类比较
- 接入建议：栏目抓取 + 人工筛选
- 优先级：P2

## 10. Craft Brewing Business
- 类别：行业商业媒体
- 价值：适合设备、运营、酒厂管理与商业端观察
- 适合内容：设备、包装、法规、运营、行业商业新闻
- 接入建议：RSS / 网页抓取
- 优先级：P1

---

## 三、酿造技术与专业知识类

这类来源是 BeerDirect 里最关键的一层之一，直接服务于技术研究和研发参考。

## 11. BYO（Brew Your Own）公开文章
- 类别：技术 / 酿造媒体
- 价值：大量实用技术文章，适合专题整理
- 适合内容：工艺、配方、原料、缺陷控制、经验总结
- 接入建议：公开文章抓取 + 人工摘要
- 优先级：P1

## 12. MBAA Tech / MBAA 公开资源
- 类别：专业技术组织
- 价值：技术深度高，适合作为专业参考层
- 适合内容：酿造工艺、质量控制、生产技术
- 接入建议：公开内容归档 + 会员内容后续评估
- 优先级：P1

## 13. Brülosophy
- 类别：实验型酿造内容
- 价值：适合做实践观察和“经验 vs 实验”对照
- 适合内容：工艺实验、变量对比、酿造假设验证
- 接入建议：栏目抓取 + 专题整理
- 优先级：P1

## 14. MoreBeer / Northern Brewer / 技术博客类公开资料
- 类别：商家公开技术内容
- 价值：基础操作性强，适合知识补充
- 适合内容：设备使用、原料应用、基础工艺知识
- 接入建议：人工筛选
- 优先级：P3

## 15. 酿造设备厂商技术博客
- 类别：设备 / 技术供应商
- 价值：有助于理解生产端趋势与设备方案
- 适合内容：CIP、罐体、发酵控制、包装线、自动化
- 接入建议：精选抓取
- 优先级：P2

## 四、原料供应商公开资料类

这一层非常重要，因为很多一手技术细节首先出现在供应商资料中。

## 16. Yakima Chief Hops
- 类别：酒花供应商
- 价值：酒花新品、品种信息、应用建议的重要来源
- 适合内容：新品种、产区、香气描述、应用案例
- 接入建议：官网内容抓取 + 产品档案整理
- 优先级：P1

## 17. BarthHaas
- 类别：酒花供应商 / 行业研究
- 价值：酒花市场与年度报告非常重要
- 适合内容：酒花趋势、市场变化、品种信息
- 接入建议：报告归档 + 年度资料专题化
- 优先级：P1

## 18. Hopsteiner
- 类别：酒花供应商
- 价值：技术资料与产品说明具有较高参考价值
- 适合内容：酒花产品、工艺应用、萃取物资料
- 接入建议：资料页归档
- 优先级：P2

## 19. Fermentis
- 类别：酵母供应商
- 价值：发酵与酵母应用资料非常实用
- 适合内容：菌株说明、发酵建议、案例、技术指南
- 接入建议：技术资料抓取 + 菌株档案整理
- 优先级：P1

## 20. Lallemand Brewing
- 类别：酵母 / 发酵解决方案
- 价值：技术内容丰富，适合专题研究
- 适合内容：菌株、营养、发酵问题、Webinar 资料
- 接入建议：技术页归档 + 精选整理
- 优先级：P1

## 21. White Labs / Omega Yeast 公开资料
- 类别：酵母品牌
- 价值：适合追踪菌株、风味特征与新产品
- 适合内容：菌株介绍、应用建议、新产品发布
- 接入建议：品牌页面整理
- 优先级：P2

## 22. Weyermann / Bestmalz / Crisp / Simpsons 等麦芽商公开资料
- 类别：麦芽供应商
- 价值：适合麦芽风味、应用与品类整理
- 适合内容：麦芽目录、风味描述、工艺建议
- 接入建议：产品资料归档
- 优先级：P2

## 五、品牌 / 酒厂官方来源类

这类来源适合建立重点品牌与酒厂档案。

## 23. Sierra Nevada 官方新闻 / 博客
- 类别：酒厂官方
- 价值：适合跟踪成熟酒厂产品、可持续、设备和品牌动作
- 适合内容：新品、合作、工艺、企业动态
- 接入建议：精选追踪
- 优先级：P2

## 24. Russian River / Other Half / Tree House / 重点酒厂官网新闻
- 类别：酒厂官方
- 价值：适合标杆品牌长期档案建设
- 适合内容：新品节奏、品牌动作、风格方向
- 接入建议：品牌池管理 + 人工精选
- 优先级：P2

## 25. 国内重点精酿品牌官方公众号 / 官网资讯页
- 类别：中国本土品牌源
- 价值：对本地趋势判断非常重要
- 适合内容：新品、联名、渠道扩张、市场语言、活动
- 接入建议：人工归档为主
- 优先级：P1

---

## 六、比赛、奖项与风格结果类

这类来源适合形成结构化数据库。

## 26. World Beer Cup Results
- 类别：比赛结果
- 价值：可建立风格与品牌获奖档案
- 适合内容：奖项、风格、酒厂、年份
- 接入建议：结构化表格化
- 优先级：P1

## 27. European Beer Star
- 类别：比赛结果
- 价值：补足欧洲方向的品牌与风格观察
- 适合内容：获奖结果、类别、趋势
- 接入建议：年度归档
- 优先级：P2

## 28. International Brewing Awards / 各类国际赛事
- 类别：比赛 / 国际奖项
- 价值：补充全球市场视角
- 适合内容：结果、类别、地区表现
- 接入建议：结构化归档
- 优先级：P2

---

## 七、市场与消费者观察类

这类来源用来补足“技术以外”的市场层。

## 29. Nielsen / IRI 等公开可访问摘要页面
- 类别：市场数据摘要
- 价值：即使不是完整数据库，公开摘要也值得跟踪
- 适合内容：零售趋势、品类增长、价格带变化
- 接入建议：人工整理
- 优先级：P2

## 30. Drizly / 零售平台趋势文章 / Total Wine 内容页
- 类别：零售观察
- 价值：有助于观察消费者偏好与品类露出
- 适合内容：热门风格、季节性趋势、品牌分布
- 接入建议：人工精选
- 优先级：P3

## 31. Reddit / 社区讨论（谨慎）
- 类别：社区 / 用户反馈
- 价值：可补充消费者感知与真实使用反馈
- 适合内容：口碑、趋势苗头、用户体验
- 接入建议：仅人工参考，不作为事实主源
- 优先级：P3

## 当前判断

BeerDirect 的公开来源第一阶段，不宜追求数量，而应追求：

- 主题覆盖完整
- 来源可信
- 能长期更新
- 便于形成结构化档案

所以第一阶段最建议的是：

- 先做 10-12 个 P1 公开源
- 再补 10 个左右 P2 源
- 暂时不把精力花在低质量、低结构化来源上
