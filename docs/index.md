# BeerDirect

持续自动搜集、整理与归档关于啤酒的各种资料和信息。

## 项目定位

BeerDirect 是一个面向啤酒行业的资料采集与知识整理项目，目标是逐步建立一个可持续更新的啤酒信息基础设施。

它将围绕以下方向持续积累内容：

- 行业新闻与动态
- 酿造技术与工艺资料
- 啤酒风格与产品研究
- 原料、设备与供应链信息
- 品牌、酒厂与市场观察
- 专题研究、摘要与报告输出

## 未来能力

- 自动采集公开信息源
- 定期更新啤酒行业资料索引
- 对内容进行分类、去重与整理
- 输出周报、月报与专题报告
- 为内容创作、产品研发与行业研究提供支持
