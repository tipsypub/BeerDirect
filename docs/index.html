把分散的啤酒资料，变成持续更新的行业知识系统。

BeerDirect 是一个围绕啤酒行业建立的信息采集、整理、归档与输出项目。它持续关注新闻、酿造技术、风格研究、原料与设备、酒厂与品牌、市场趋势和专题分析，并逐步形成可检索、可追踪、可复用的知识底座。

Workflow

BeerDirect 不只是收集链接，而是把原始资料加工成后续可搜索、可分析、可输出的结构化知识。

1

Collect

从公开站点、RSS、文章、比赛、品牌与技术来源中持续采集信息。

2

Clean

对原始资料做清洗、去重、标准化与来源记录，建立可靠输入层。

3

Classify

按主题、风格、技术标签、品牌、原料与时间线进行结构化分类。

4

Export

输出成专题文档、摘要、周报、月报或后续 AI 可直接调用的知识材料。

About the project

BeerDirect aims to build a continuously updated knowledge base for beer-related information, transforming scattered sources into a usable intelligence layer for research, content, and product thinking.
