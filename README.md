# BeerDirect

BeerDirect 是一个面向啤酒领域的信息持续采集、整理与输出仓库。

它的核心目标不是做单一资料存档，而是建立一套可持续更新的啤酒知识基础设施：持续自动搜集全球与本地关于啤酒的各种资料、新闻、技术文章、风格信息、原料动态、设备趋势、市场信息与行业观察，并将这些内容进行结构化整理，方便后续检索、分析、再利用与内容生产。

## 项目目标

- 持续自动搜集啤酒相关资料与信息
- 对分散来源的信息进行清洗、归类和去重
- 建立结构化的啤酒知识库与主题档案
- 为选题策划、产品研发、市场判断、内容创作提供支持
- 逐步形成可检索、可追踪、可复用的行业信息系统

## 计划覆盖的内容范围

### 1. 行业新闻
- 精酿行业动态
- 啤酒品牌与酒厂新闻
- 市场趋势与渠道变化
- 国际比赛、展会、奖项信息

### 2. 酿造技术
- 原料技术（麦芽、酒花、酵母、水处理、辅料）
- 工艺优化与发酵控制
- 啤酒稳定性、澄清、氧化控制
- 新技术、新设备、新流程

### 3. 风格与产品研究
- 啤酒风格资料整理
- 经典产品与标杆案例分析
- 新风格、新配方、新趋势追踪
- 地域性与本土化产品研究

### 4. 供应链与商业信息
- 原料供应与价格趋势
- 包装、设备与耗材信息
- 进口、代理、渠道与零售观察
- 酒吧、门店、消费者动向

### 5. 知识归档与专题研究
- 专题资料汇编
- 重点品牌/酒厂档案
- 重点技术主题档案
- 访谈、文章、论文与公开资料摘录

## 预期能力

后续这个仓库可以逐步扩展出以下能力：

- 自动抓取指定来源的公开信息
- 定时更新啤酒新闻与资料索引
- 按主题自动分类与标签化
- 输出摘要、周报、专题报告
- 建立面向人和 AI 的统一知识输入层

## 适用场景

BeerDirect 未来可以服务于以下工作：

- 啤酒行业资料追踪
- 新品研发参考

- 采访与内容创作准备
- 品牌与竞品研究
- 啤酒知识助手的数据底座建设
